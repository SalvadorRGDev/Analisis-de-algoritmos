Que es un algoritmo?
es una seria de pasos ordenados que tienen como finalidad llevar a cabo un objetivo que tenga un resultado consistente. Los algoritmos deben estar definido, sin tener ambiguedades en sus partes.

Para la comparacion de dos algortimos se tomara en cuenta un factor como la entrada, este se denotara por la letra "n", por ejemplo no es lo mismo tener un sort normal con 10 elementos, a un sort con mil elementos.

Notacion asintotica

O(1): Constante
O(log n): creciimiento lento
O(n): proporcional
O(n^2): se dispara rapido

Complejidad espacial: cantidad de memoria que requiere el algoritmo
COmplejidad temporal: tiempo que toma el algoritmo en ejecutarse
